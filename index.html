2. Mathematical Expression

A mathematical expression is a combination of numbers, variables, operators, and symbols. An expression does not have to contain an equals sign.

3x + 7
2(a + b) − 5
x² + 4x + 4

Example

If x = 4, then:

3x + 7 = 3(4) + 7 = 19

3. Set

A set is a well-defined collection of distinct objects. The objects in a set are called elements or members.

A = {1, 2, 3, 4, 5}

Here, 1, 2, 3, 4, and 5 are elements of set A.

2 ∈ A     8 ∉ A

Sets can be written using roster (listing) notation or set-builder notation.

4. Set-Builder Notation

Set-builder notation describes a set by stating a rule or condition that its elements satisfy.

A = {x | x is a natural number and x < 6}

The vertical bar | means “such that.” The same set can be listed as:

A = {1, 2, 3, 4, 5}

Another example

B = {x ∈ ℤ | −2 ≤ x ≤ 2}

Therefore:

B = {−2, −1, 0, 1, 2}

6. Venn Diagram

A Venn diagram represents sets using circles. Overlapping regions show elements common to two or more sets.

A
B
A ∩ B
A ∪ B = elements in A or B
A ∩ B = elements common to A and B

Example: If A = {1,2,3} and B = {3,4,5}, then:

A ∩ B = {3}
A ∪ B = {1,2,3,4,5}

7. Reasoning: Deductive and Inductive

DEDUCTIVE

Deductive Reasoning

Starts with a general rule or principle and applies it to a specific case.

All squares have four sides.
ABCD is a square.
∴ ABCD has four sides.

Pattern: General → Specific

INDUCTIVE

Inductive Reasoning

Starts with specific observations and uses them to form a general conclusion or conjecture.

2 + 4 = 6
4 + 6 = 10
6 + 8 = 14
∴ The sum of two consecutive even numbers is even.

Pattern: Specific → General
